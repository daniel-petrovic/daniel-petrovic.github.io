  <article class="cv-item">
    <p class="post-meta">2022 &mdash; Present</p>
    <h3>Embedded Software for Dental Lab Equipment &amp; CNC Milling</h3>
    <p><strong>EBCONT group GmbH, Austria</strong></p>
    <p><strong>Problem:</strong> Legacy Windows 7 Compact Embedded hardware was reaching end-of-life while the product still needed reliable CNC control, production testing, and remote management.</p>
    <p><strong>Solution:</strong> Made major contributions to the transition to a Yocto Linux platform on i.MX8 hardware, built a reusable application framework, implemented OPC UA server functionality within the framework, integrated CNC control with strict timing constraints, added CAN, EEPROM, RFID, Mender OTA, Azure IoT, and Qt6/QML components, and fixed hard-to-find bugs including memory leaks and threading issues.</p>
    <p><strong>Impact:</strong> Reduced Azure DevOps CI/CD build times by over 40%, improved automated production testing, helped meet critical project deadlines, and supported production of hundreds of dental lab devices worldwide.</p>
  </article>

  <article class="cv-item">
    <p class="post-meta">2017 &mdash; 2022</p>
    <h3>Simulation &amp; PLC Communication for Warehouse Management</h3>
    <p><strong>LTW Intralogistics GmbH, Austria</strong></p>
    <p><strong>Problem:</strong> Automated warehouse projects needed reliable PLC communication, simulation tooling, diagnostics, and host integration before and during customer deployments.</p>
    <p><strong>Solution:</strong> Built C++/MFC and C#/WPF simulation environments and control services for Siemens S7 PLCs, implemented ISO TCP/RFC1006 communication, modernized legacy components, added T-SQL database workflows, and supported on-site integration.</p>
    <p><strong>Impact:</strong> Delivered simulation and control software for automated warehouses managing thousands of storage locations, reducing integration risk before customer go-live.</p>
  </article>

  <article class="cv-item">
    <p class="post-meta">2013 &mdash; 2017</p>

    <p><strong>Solution:</strong> Developed C++/Qt/Python applications for thermochemical and fluid-dynamic calculations and contributed to EU research projects with academic partners.</p>
    <p><strong>Impact:</strong> Supported sales engineering and helped improve efficiency and reduce emissions across multiple industrial biomass plants in Europe.</p>
